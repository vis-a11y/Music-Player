# Music Player

A simple web-based music player built with HTML, CSS, and JavaScript.

## Features

- Play / pause controls
- Next / previous track
- Progress bar and seek
- Simple playlist support


## Usage

- Click a song in the UI (if a playlist is present).
- Use the play/pause and next/previous buttons to control playback.
- Drag the progress bar to seek.

## Project Files

- index.html — main UI
- script.js — player logic
- style.css — styling

## Development

- Edit the files in your editor and refresh the browser to see changes.
- For a better development experience use the VS Code Live Server extension.
