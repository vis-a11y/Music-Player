## 🌟 About the Project

**Music Player** is a lightweight, interactive audio application that runs entirely in your browser. It was built from scratch to demonstrate proficiency in frontend web development, specifically focusing on the HTML5 Audio API, DOM manipulation, and real-time state management. 

Without relying on any external libraries or frameworks, this project provides a clean user interface and lag-free audio playback controls, ensuring a seamless user experience.

---

## ✨ Features

### 🎧 Playback & Interactions
| Feature | Description |
|---|---|
| ⏯️ **Play / Pause** | Toggle audio playback instantly with synced UI updates |
| ⏭️ **Track Navigation** | Effortlessly skip forward or backward through the playlist |
| 🎚️ **Progress Bar** | Visual timeline that updates in real-time as the song plays |
| 🖱️ **Precision Seeking** | Click anywhere on the progress bar to instantly jump to that timestamp |
| 🎼 **Dynamic Playlist** | Interact directly with the playlist to select specific tracks |
| 📱 **Responsive Design** | UI adapts perfectly to mobile, tablet, and desktop screens |

## 🧰 Tech Stack

### Frontend
- **HTML5** — Semantic page structure and native `<audio>` integration
- **CSS3** — Custom properties, flexbox layouts, hover states, and smooth transitions

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser and a code editor. No Node.js or build tools required!

- A modern browser (Chrome, Firefox, Safari, Edge)
- [VS Code](https://code.visualstudio.com/) (Recommended)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/Music-Player.git
   cd Music-Player
   ```

2. **Add your music (Optional)**
   Place your own `.mp3` files inside the `songs/` directory and update the playlist logic in `script.js` to match your new files.

### Running Locally

Since this is a static frontend project, there is no need for a complex local server.

1. Open `index.html` directly in your browser.
2. **Alternatively (Recommended):** Use the **Live Server** extension in VS Code. Simply right-click `index.html` and select "Open with Live Server" to get automatic reloads when you make changes to the code.
